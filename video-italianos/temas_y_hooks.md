# Temas con potencial de vistas + títulos/hooks

Criterios: búsquedas altas de "nombres para bebé", curiosidad (origen, significado), identidad
(país, religión, estilo), listas cortas con "el último es mi favorito" para retener hasta el final,
y una pregunta final que invita a comentar (el algoritmo premia comentarios y guardados).

| Tema | Título en pantalla | Hook de voz (primeros 3 s) |
|------|--------------------|----------------------------|
| Nombres italianos para niña | Nombres ITALIANOS para niña 🇮🇹 | "¡Nombres italianos que suenan a pura dolce vita!" |
| Nombres italianos para niño | Nombres ITALIANOS para niño | "Si quieres un nombre con estilo de galán italiano… mira esto." |
| Nombres cortos (4 letras o menos) | Nombres CORTITOS y preciosos | "Cortos, dulces y fáciles de gritar en el parque." |
| Nombres que significan "luz" o "sol" | Nombres que significan LUZ ☀️ | "Estos nombres literalmente significan luz." |
| Nombres bíblicos poco comunes | Nombres BÍBLICOS que casi nadie usa | "Bíblicos, bonitos… y casi nadie los usa." |
| Nombres de princesas / reinas | Nombres de REINAS para tu bebé 👑 | "Para una bebé que va a mandar en casa… desde el día uno." |
| Nombres que combinan con hermanos | Nombres para HERMANITOS que combinan | "¿Ya tienes uno y buscas el nombre perfecto para el segundo?" |
| Nombres que suenan igual en inglés y español | Nombres que funcionan en INGLÉS y ESPAÑOL | "Perfectos si tu familia es bilingüe." |
| Nombres de flores | Nombres de FLORES 🌸 | "Nombres tan bonitos que florecen solos." |
| Nombres mitológicos (griegos/nórdicos) | Nombres de DIOSAS | "Nombres de diosas… literalmente." |
| Nombres por letra (A, M, L…) | Nombres para niña con M | "Si te gusta la M, guarda este video." |
| Nombres que están de moda este año | Los nombres MÁS elegidos este año | "Estos son los que más están eligiendo las mamás." |
| Nombres "prohibidos" / raros de verdad | Nombres que NO sabías que existían | "Apuesto a que no conoces el número tres." |
| Nombres japoneses / nórdicos / árabes | Nombres JAPONESES con significado | "Cada uno tiene un significado precioso." |

Formato recomendado: 10 nombres, ~5 s por nombre, gancho de 4–5 s, cierre con pregunta + "guárdalo".
